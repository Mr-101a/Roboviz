# Roboviz 
**Mr.101 || Soccer Simulation 3D**  

A monitor for Soccer Simulation 3D that has better quality than the main monitor of this league and connects to the internal host ((after running the server))
   
- After extracting, open the corresponding folder in the terminal :
  
```cd RoboViz/bin```
- and then enter this command :
  
```./roboviz.sh```
